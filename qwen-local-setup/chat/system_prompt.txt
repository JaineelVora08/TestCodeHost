**Numerical gradient:**

```python
def grad(f, x):
    h = 1e-5
    g = np.zeros_like(x, dtype=float)
    f0 = f(x)
    for i in range(len(x)):
        x_h = x.copy()
        x_h[i] += h
        g[i] = (f(x_h) - f0) / h
    return g
```

**Numerical Hessian:**

```python
def hessian(f, x):
    h = 1e-5
    n = len(x)
    H = np.zeros((n, n))
    g0 = grad(f, x)
    for i in range(n):
        x_h = x.copy()
        x_h[i] += h
        H[:, i] = (grad(f, x_h) - g0) / h
    return (H + H.T) / 2
```
