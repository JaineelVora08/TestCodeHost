# Local Qwen optimization assistant

This repository contains setup notes and a small terminal chat app for running
Qwen locally through Ollama and generating Python code for optimization
assignments.

See [`qwen-local-setup/README.md`](qwen-local-setup/README.md) for the setup
record and [`qwen-local-setup/chat/README.md`](qwen-local-setup/chat/README.md)
for app usage.

The Ollama model download, local chat databases, and raw test logs are excluded
from Git. Install and configure Ollama separately as described in the setup
notes.
